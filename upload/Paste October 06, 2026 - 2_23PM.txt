RULE 20:

RULE 21:

RULE 22:

RULE 23:

RULE 24:

24. VALIDATION ENGINE
============================================================

Validation is system-driven.

Every record must be checked for:

- required field
- reporting period
- organization scope
- correct unit
- valid numeric format
- negative values where prohibited
- valid conversion
- duplicate risk
- missing evidence
- inconsistent dates
- unusual ranges
- cross-field consistency
- source/document consistency
- historical anomalies
- factor availability

Validation severity:

INFO
WARNING
ERROR
BLOCKING

Example:

Diesel = 5000 liters
→ valid unit
→ convert liters to configured energy unit
→ apply factor/version
→ calculate CO2e
→ store result

Validation response must explain:
- issue
- field
- severity
- reason
- suggested action
